# 우리 가족 영어 시간: 기획서

> 마지막 업데이트: 2026-11-28 · 상태: 0단계 진행 중 (저학년 대본형 대화 완성, AI 자유 대화는 API 키 대기)

## 1. 컨셉
**가족이 각자 AI 친구와 영어로 대화하고, 기록은 가족끼리 공유하는 웹앱**

- 목적: 개인용(학습용). 우리 가족이 실제로 쓰는 것이 목표이고, 결제나 스토어 출시는 하지 않음
- 개발: 1인 개발, 개발 경험 없음 → Claude Code와 함께 개발

**한 문장 정의:** 영어를 가르쳐주고 싶지만 본인도 자신이 없는 부모와 아이가, AI 대화 상대와 함께 매일 10분씩 영어로 말하는 습관을 만든다.

## 2. 사용자
| 구분 | 상황 | 불편 |
|---|---|---|
| 부모 | 아이 영어교육에 관심이 많음 | 본인 영어가 부족해서 집에서 도와주기 어려움 |
| 아이 (초등 저학년/고학년) | 학원이나 학교에서 영어를 배움 | 배운 걸 말해볼 기회가 없고, 말하기가 부끄러움 |

### 사용 시나리오
- **저학년 아이:** 부모 폰/태블릿에서 자기 프로필 선택 → AI가 쉬운 질문 → 짧게 대답 → 칭찬 스티커 → 5분 내 종료
- **고학년 아이:** 주제 선택 → 5~10턴 대화 → "이렇게 말하면 더 자연스러워요" 표현 2~3개 확인
- **부모:** 출퇴근길에 대화 연습 → 가족 보드에서 아이 기록 확인, 응원 남기기

## 3. 핵심 결정
| 항목 | 결정 |
|---|---|
| 가족 구조 | (B) 각자 학습 + 기록 공유 |
| 계정 | 가족 계정 1개 + 프로필 전환 (넷플릭스 방식) |
| 아이 레벨 | 초등 저학년 / 초등 고학년 중 선택 |
| 플랫폼 | 웹앱 (PWA로 홈 화면에 추가) |
| 대화 방식 | 저학년: 대본형 (무료, 보기 선택) / 고학년·부모: AI 자유 대화 (Claude API) |
| AI | Claude API, 레벨별 시스템 프롬프트로 말투 조절. 비용 때문에 키 발급은 보류 중 |

### 레벨별 차이
| | 초등 저학년 | 초등 고학년 | 부모 |
|---|---|---|---|
| AI 말투 | 아주 쉬운 단어, 짧은 문장 | 쉬운 일상 표현 | 자연스러운 속도 |
| 대화 길이 | 3~5턴 | 5~10턴 | 자유 |
| 막힐 때 | 보기 2개 제시 | 한국어 힌트 | 한국어 힌트 |
| 피드백 | 칭찬과 스티커만 | 칭찬 + 표현 추천 | 문법 교정 + 표현 추천 |
| 화면 | 큰 글씨, 캐릭터 중심 | 자막 표시 | 자막 + 번역 |

## 4. 화면 흐름
```
[가족 로그인] → [프로필 선택]
                     │
                     ▼
                [홈 화면]
         ┌───────────┼────────────┐
         ▼           ▼            ▼
    [주제 선택]   [가족 보드]    [내 기록]
         │
         ▼
    [AI 음성 대화] → [대화 결과/피드백] → 가족 보드에 자동 기록
```

## 5. 기술 스택
| 역할 | 선택 |
|---|---|
| 웹앱 | Next.js (TypeScript) + Tailwind CSS |
| 배포 | Vercel |
| 로그인·DB | Supabase (3단계부터) |
| 음성 인식/재생 | 브라우저 내장 음성 기능. 읽어주기는 대본형에 적용 완료, 음성 인식은 1단계 |
| 대본 | `scripts/` 폴더의 텍스트 파일. 작성법은 `scripts/README.md` |
| AI 대화 | Claude API (`@anthropic-ai/sdk`) |

## 6. 로드맵
| 단계 | 만드는 것 | 확인할 것 | 상태 |
|---|---|---|---|
| 0 | 저학년 대본형 대화 (대본 3개, 읽어주기, 별 모으기) | 아이가 재미있어하는지 | ✅ 완료 |
| 0 | 텍스트로 AI와 대화 | 레벨별 AI 말투가 괜찮은지 | ⏸ API 키 대기 |
| 1 | 음성 대화 (마이크 입력, 음성 출력) | 아이 발음을 잘 알아듣는지 | ⬜ |
| 2 | 주제 확장, 대화 후 피드백 화면 | 아이가 재미있어하는지 | ⬜ |
| 3 | 가족 계정, 프로필 전환, 기록 저장 | 여러 기기에서 동기화되는지 | ⬜ |
| 4 | 가족 보드 (스트릭, 스티커, 응원) | 매일 쓰게 되는지 | ⬜ |

## 7. 주의할 점
- **아동 정보:** 부모 계정 아래에 아이 프로필을 두는 구조. 실명, 학교, 주소 등은 묻지 않음. 아이 음성은 저장하지 않음
- **AI 안전:** 시스템 프롬프트로 가족 친화적인 주제만 다루도록 제한 (`src/lib/levels.ts`)
- **비용:** 대화 길이와 메시지 길이를 서버에서 제한. Claude Console에서 월 사용 한도 설정 권장
