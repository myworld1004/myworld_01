# 대본 쓰는 법

`kid_low/` 폴더에 있는 `.txt` 파일 하나가 대본 하나입니다. 파일을 복사해서 새 대본을 만들 수 있어요.

```
title: 음식                     ← 화면에 보이는 주제 이름
emoji: 🍕                       ← 주제 아이콘

Bubbles: Are you hungry? | 배고프니?          ← Bubbles 가 하는 말 | 한국어 뜻
* Yes, I am! | 응, 배고파! => Me too! | 나도!   ← 아이가 고르는 보기 | 뜻 => Bubbles 반응 | 뜻
* No, I'm not. | 아니, 안 고파. => Okay!       ← 반응은 생략해도 돼요

end: Great job, {name}! | 잘했어, {name}!     ← 마지막 인사
```

규칙
- `Bubbles:` 한 줄 다음에 `*` 보기를 2~3개 적고, 빈 줄로 다음 장면과 구분해요.
- `|` 뒤의 한국어 뜻은 없어도 됩니다.
- `{name}` 은 아이 이름으로 바뀌어요.
- 형식이 틀리면 `npm run dev` 화면에 몇 번째 줄이 틀렸는지 알려줘요.
